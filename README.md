# My eXp + MIRA

UX case study and clickable screen walkthrough for My eXp with MIRA, a conversational assistant for real estate agents.

- Case study: `index.html`
- Interactive walkthrough: `walkthrough.html` (hotspots link screens; arrow keys for next/prev; H shows hotspots)

Concept prototype built with demo data. All names and figures are fictional. This is not an official eXp product.

Design and case study by Suvarna Myneni.
