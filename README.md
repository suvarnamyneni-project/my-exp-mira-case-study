# My eXp + MIRA

UX case study and clickable screen walkthrough for My eXp with MIRA, a conversational assistant for real estate agents.

- Case study: `index.html`
- Screen walkthrough: `walkthrough.html` (arrow keys for next/prev; hotspots on earlier-prototype screens, H shows them)

Design work I did as a UX designer at eXp Realty on the My eXp agent portal; MIRA and some other areas are shown as earlier prototype designs. All names, figures and transactions shown are demo data and fictional. Shared for portfolio purposes; eXp and My eXp are trademarks of their respective owners.

Design and case study by Suvarna Myneni.
